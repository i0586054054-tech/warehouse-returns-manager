# Warehouse Returns Manager

מערכת React + Vite + Supabase לניהול החזרות במחסן.

## מה כבר קיים
- דשבורד שמחשב אוטומטית את היום המקומי בדפדפן ומציג מה קורה היום.
- סוכנים שמגיעים היום והפריטים שממתינים להם.
- רשימת החזרות שמוכנות לשליחת WhatsApp.
- כפתור מרכזי להעלאת תמונת החזרה.
- העלאת כמה תמונות יחד וניסיון לקרוא ברקוד מכל תמונה באמצעות BarcodeDetector בדפדפנים תומכים.
- חיפוש ברקוד/קוד פריט מול `product_catalog`.
- התאמה אוטומטית לחברה, שיטת טיפול, סוכן ומיקום לפי הנתונים שהוגדרו.
- כפתור לקליטת כל התמונות שזוהו בפעולה אחת.
- מסך הגדרות לחברות, סוכנים ומדפים.

## הפעלה מקומית
1. צור `.env` לפי `.env.example` עם פרטי Supabase שלך.
2. `npm install`
3. `npm run dev`

## שדרוג בסיס הנתונים
אם בסיס הנתונים הקיים עדיין לא כולל `companies`, `storage_locations`, `product_catalog` והשדות החדשים, הרץ פעם אחת ב-Supabase SQL Editor את:

`supabase/smart_intake_upgrade.sql`

## אבטחה
`.env` מוחרג מ-Git ולעולם לא צריך להעלות אותו ל-GitHub.
